このアプリについて

「home-publish」は、YouTube チャンネル「ふしぎの小箱」の運営者が、自分で作った動画を自分のチャンネルに投稿するためだけに使う個人用のツールです。運営者以外の人は使いません。

使う Google のデータ

YouTube API サービス(YouTube Data API v3)を使い、運営者のチャンネルに対して次のことだけを行います: 動画のアップロード、公開日時の設定・変更、自分の動画の状態の確認。ほかの人のアカウントやデータにはアクセスしません。

保存と共有

認証のための情報(トークン)は、運営者が管理する非公開のサーバーに、運営者だけが読める形で保存します。データを第三者に売ったり、渡したりすることはありません。

アクセスの取り消し

このアプリへのアクセスは、Google アカウントの設定からいつでも取り消せます。

YouTube と Google の規約

このアプリは YouTube API サービスを使っています。YouTube 利用規約と Google プライバシーポリシーもご覧ください。

English

"home-publish" is a personal tool used only by the owner of the YouTube channel "ふしぎの小箱" to upload the owner's own videos to the owner's own channel. Using the YouTube API Services (YouTube Data API v3), it only uploads videos, sets or updates their publish time, and checks the status of the owner's own videos. It does not access any other user's account or data. The authorization token is stored on the owner's private server, readable only by the owner. No data is sold or shared with third parties. Access can be revoked at any time at Google Account permissions. See also the YouTube Terms of Service and the Google Privacy Policy. Contact: brwhzerone120902.publish@gmail.com
